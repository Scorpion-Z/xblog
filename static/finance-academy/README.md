# 企业财务研习室

该专题位于“超能日志”Hugo博客的独立静态页面，访问路径为 `/xblog/finance-academy/`。

## 内容

- 8个模块，共32节中文课程。
- 每节包含三个知识判断、一个模拟业务案例、借贷分录、误区提示及带解析的单选题。
- 3套连续案例：自主科研费用化与资本化、受托技术开发、集团内部交易及合并。
- 1个可输入金额并即时核对答案的综合账务演练。
- 18项财务术语词典。
- 浏览器本地保存已完成课程、测验选择及深浅主题。

## 文件结构

- `index.html`：页面结构和资源引用。
- `styles.css`：响应式视觉样式。
- `curriculum.js`：课程、术语、综合计算题和政策链接。
- `case-studies.js`：三套连续业务案例、分录、核对结果。
- `app.js`：页面路由、目录、进度、本地缓存和交互功能。

## 如何维护

课程内容在 `curriculum.js` 的 `modules` 内编辑，保持原有 `id` 不变以免影响学习记录。增加课程时，请同步核对页面声明的课程数量及学时，并确保各练习答案与解题说明一致。

连续业务案例在 `case-studies.js` 内维护，每一步通过 `rows` 记录借贷分录。增添或调整案例时，必须核对借贷双方金额一致、资金变动、期末资产、利润和权益勾稽。

示例中关于资本化、收入确认、税费和合并抵销的前提均应明确列示。官方准则与相关指引的链接位于 `curriculum.js` 的 `sources` 字段，更新内容时应重新检查政策时效。

本站没有后端，不收集学习记录。学习进度通过浏览器的 `localStorage` 保存；更换设备或清理浏览器数据时，记录可能丢失。

## 集成及部署

博客使用Hugo与PaperMod。项目文件放在 `static/finance-academy/` 下，Hugo构建时会原样复制。博客菜单入口在根目录 `hugo.toml` 与两个主题配置文件中添加为“财务学堂”。

推送到主分支后，仓库的GitHub Actions工作流 `.github/workflows/hugo.yml` 执行构建并部署到GitHub Pages。

## 内容性质

全部公司名称、业务数据、科目示例和金额均用于教学，不代表真实央企内部账务。实际业务处理应结合有效企业会计准则、税收政策、合同权利义务和本单位会计政策，由具有相应职责的专业人员判断。
