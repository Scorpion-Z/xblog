理解 01

储能解决的是时间错配。它将一部分能量从有富余的时候转移到需要的时候，但存储容量、充放电功率和损耗都会限制转移效果。电池不能凭空发电。

理解 02

容量大不一定功率大，倍率高也不代表必须快速放电。评审“100MW/200MWh”的储能电站时，两者相除得到名义持续时间2小时，真实系统还要考虑效率、SOC窗口和工作限制。

EXPERIMENT 03 / C RATE

为什么30C，
理论上只要2分钟？

别急着背公式。先把额定容量想成一桶水，C倍率决定按多大流速放水，再看时间如何变化。

C-RATE / CURRENT / TIME额定容量设为10Ah

提高倍率，速度增加多少？

点击1C、5C、30C，再看电流和时间。额定容量固定为10Ah，假设恒流且能够完整放出额定Ah。

I = C × Q

Q=10Ah；I为电流（A）。如30C×10Ah=300A。倍数对应额定容量的放电电流，而不是用电器数量。

t = 1 ÷ C 小时 = 60 ÷ C 分钟
1C的含义：按额定容量对应的电流，理想情况下1小时放出额定Ah容量。

真实电芯在高倍率下，电压跌落、温升和提前截止可能导致无法放出全部额定容量。能量Wh与安时Ah也要区分。充电30C和放电30C更不能互相推导。

能量密度：Wh/kg

1kg电芯有100Wh标称能量，代表每公斤储存0.1度电。要确认计算的是材料质量、完整电芯还是系统重量。

功率密度：W/kg

衡量单位质量的输出功率。高倍率下是否能持续输出、持续多久、发热多高，要看实际测试曲线。

理解 03

公式中的“60”只来自1小时等于60分钟。30C与100Wh/kg两个独立的性能指标，不能证明一个真实电芯能够在30C工况下完整释放标称100Wh/kg能量。

同属于电池，为什么又分那么多种？

磷酸铁锂和三元锂都是锂离子电池的不同正极路线。钠离子、铅酸、液流电池则采用不同的材料与结构。它们的能量、功率、寿命、安全和成本各有取舍。

锂离子电容器是什么？

它结合了电池型电极与电容型电极的储能机制，尝试兼顾能量和功率。评审时要看同一完整电芯在同一工况下的测试数据，而非两张最漂亮的单项指标。

EXPLORER 05 / 系统透视

一座储能电站，
究竟由哪些设备组成？

电芯只是开始。储能要真正给家庭或电网供电，需要电能变换、状态监测、控制策略、安全与热管理。

电芯与电池包

电芯是储电基本单元。通过合理串并联组成模组和电池簇。电芯需要保护，不具备直接把电送入家庭交流插座的全部能力。

理解 05

电芯标称100Wh/kg，并不等于储能电站系统达到100Wh/kg。模组、机柜、冷却、PCS、消防等设备增加了重量与成本。系统效率还要明确是在直流侧还是交流侧测量。

EXPERIMENT 06 / 电力调频

电网频率偏了，
储能能帮什么忙？

在50Hz电网中，频率变化可以反映有功功率供需的失衡趋势。储能可按控制策略快速增减有功功率。

理解 06

调频更关心响应速度、持续功率、频繁循环与SOC管理。系统不仅要“反应快”，也要能够在规定时间内持续输出或吸收能量。

STORAGE SIZING最小容量估算 / 非工程设计

一步步算需要的容量

按恒定有功负载和固定效率估算；这里的“可用比例”用于模拟SOC窗口或容量保留，不含老化裕度。

标称电能 ≥ 功率 × 时间 ÷ (可用比例 × 效率)
所需最低标称电能10.87 kWh
所需连续交流功率2 kW
实际交付到负载的电能8 kWh

实际选型仍须考虑电机启动冲击功率、电池衰减、温度、保护和系统工程裕度。

理解 07

计算结果只是最低值。真实方案还需考虑系统连接、消防、并网规范、厂商测试、电池寿命、全生命周期成本和当地电价等因素。不要把网页估算值直接作为采购容量。

PROFESSIONAL LEVEL / 技术判断

从会用公式，
到会质疑一组指标。

一项研发计划写着“100Wh/kg、30C”。这个数字有意义，但要知道它说的到底是什么、怎样测试、能否在同一产品上同时成立。

如果报告只给出100Wh/kg、30C，你最应该先追问什么？

选择一个答案，查看为什么。

技术上还应看什么？

同一完整电芯的电压、电流和能量曲线，高倍率温升、循环寿命、容量保持、热失控及安全测试；还要区分实验样机和成熟量产产品。

工程上还应看什么？

系统级功率、可用电能、往返效率、设备成本、持续运行和应用场景要求。峰谷套利还必须考虑电价机制、充放电损耗与退化成本。
