一份十几页的工作汇报，交给大模型，几秒钟就能得到一份摘要。摘要通常没有太大问题，却未必能回答读者真正关心的事。

例如，一份岗位价值评估材料写明哪些岗位提级、哪些岗位降级，也说明了未来的薪酬管理原则。读完摘要，我们仍然可能不知道：岗位降级后，现有员工会不会降薪？什么时候执行？影响多少人？这些问题决定了改革的实际影响，却可能没有在材料里交代。

阅读报告时，我更希望大模型做三件事：**找出已经说清楚的事实，检查结论依据，指出尚未回答的关键问题。**

下面整理了六组可以直接复制的提示词。包括日常速读、完整分析、管理决策、学术论文、行业研究和反向核验。文中的案例做了概括处理，不涉及具体单位。

## 怎样使用

日常阅读先用第一组。如果材料关系到重要判断，用第二组完整分析；遇到特定类型的文件，再补充第三至第五组中的一组。对重要结论，最后使用第六组做反向核验。

提示词只是给模型一个检查框架。输出是否可靠，还取决于原文质量、模型能力和能否核对原始证据。

## 01. 快速读懂一份材料

用于第一次阅读，要求模型把重要信息放在前面，减少逐段转述。

{{< prompt id="quick-read" title="快速阅读：核心内容与关键问题" category="通用" use="会议前速读、工作汇报、政策材料、一般报告" >}}
请阅读我提供的材料，帮助我快速理解其核心意思。

按以下顺序输出：
1. 一句话概括：这份材料最主要想说明或解决什么问题？
2. 三至五个要点：保留关键事实、数字、变化和结论。
3. 主要逻辑：作者依据什么，得出了什么判断？
4. 实际影响：对相关人员、业务或决策可能意味着什么？
5. 尚未说清楚的问题：列出最值得进一步确认的三项。

要求：
- 优先使用原文的事实和术语，不要添加未经证实的背景。
- 明确区分已确定的事项、拟议事项和作者的判断。
- 重要内容标注页码或章节，方便我回看原文。
- 如果材料没有回答某个问题，直接说明“原文未交代”。
- 文字简洁、具体，避免重复原文及空泛评价。
{{< /prompt >}}

## 02. 完整分析：从事实走向判断

这是最常用的一组。它把分析分为事实、逻辑、推断、问题和决策价值几个部分，尽量防止模型把猜测写成结论。

{{< prompt id="full-analysis" title="完整分析：事实、逻辑、隐含问题与结论" category="通用" use="重要汇报、咨询报告、政策文件、长篇研究材料" >}}
请对我提供的材料进行深入阅读和批判性分析。目标是帮助我理解内容、检验论证并形成有依据的判断。

一、核心内容
- 用一句话概括材料真正要表达的中心意思。
- 提炼三至五个重要结论及其关键依据。
- 区分事实、数据、作者判断、建议、待决事项和已批准事项。

二、论证逻辑
- 说明作者如何从问题、证据走向结论。
- 找出关键假设及其成立条件。
- 检查论据是否充分，有无因果混淆、逻辑跳跃、概念偷换或数据口径不一致。

三、值得推敲的隐含信息
- 分析材料可能反映的管理意图、资源配置方向或研究价值。
- 识别可能受到影响的组织、业务、人员或其他利益相关方。
- 找出作者未直接回答、但会影响最终判断的重要问题。
- 每项推断都要说明依据和不确定性，不要臆测动机。

四、证据与风险
- 指出数据不足、论据薄弱、概念模糊和条件缺失之处。
- 分析实施障碍、潜在副作用和结论失效的条件。
- 指出可靠的结论，以及尚待验证的判断。

五、实际价值
- 说明材料对管理决策、实际工作或相关研究有什么作用。
- 指出值得借鉴的做法，以及需要附加条件才能采纳的建议。
- 如有必要，给出具体、可操作的改进建议。

六、关键追问
- 提出最值得追问的五个问题。
- 对每个问题说明：原文已提供什么、还缺什么、不同答案可能怎样改变判断。

七、最终判断
- 用一段话给出综合评价。
- 列出最值得记住的三个结论。
- 点明一个最重要、最容易被忽略的问题。

贯穿全文的要求：
- 对重要结论标注原文页码、章节或表格位置。
- 使用“原文明确说明”“根据原文推断”“尚待核实”区分证据等级。
- 原文没有提供的数据和结论，不得自行补齐。
- 允许肯定原文的合理之处，也允许指出问题；不要为了批判而刻意挑错。
- 先提供简明结论，再解释证据和推理过程。
{{< /prompt >}}

## 03. 管理决策：领导真正需要判断什么

工作请示和改革方案有一个共同点：材料可能写了大量背景、过程和工作成绩，真正需要审议的事项却只有几项。

读这类文件，应当特别关注**决策事项、权责变化、成本影响、执行条件和未解决的问题**。

{{< prompt id="management" title="管理决策材料：审什么、改什么、影响谁" category="管理" use="党委会、董事会、经营分析会、改革方案、项目请示" >}}
请站在企业经营管理者和会议审议人员的角度分析这份材料。

重点回答：
1. 这份材料希望决策层批准、认可或了解什么？哪些事项尚无明确决策？
2. 作者提出调整的理由是什么？证据是否足够？
3. 方案实施后，管理权、决策权、责任和资源配置会发生哪些变化？
4. 哪些单位、岗位或人员受益？哪些可能承担新增成本、责任或约束？
5. 是否说明资金来源、成本变化、人员影响、实施时间、考核标准和过渡安排？
6. 如果相关安排没有说明，会给执行带来什么实际问题？
7. 哪些事项需要附条件批准、补充测算或进一步论证？

请输出：
- 一段简明的决策摘要。
- 一张“拟决策事项、原文依据、缺失信息、可能影响”的表格。
- 最值得在会上追问的五个问题，按对决策的重要程度排序。
- 你对方案可执行性的判断及其依据。

只依据材料和可核验的证据作判断。不要把尚处于研究、建议或审批阶段的事项写成已经实施。
{{< /prompt >}}

## 04. 学术论文：检查研究能证明什么

学术论文尤其需要区分作者提出的主张与研究实际证明的内容。阅读时不能只看摘要和结论，还需要看研究设计、样本、方法及局限。

{{< prompt id="academic" title="学术论文：方法、证据、创新与局限" category="学术" use="科研论文、实验报告、学术综述、预印本" >}}
请以学术同行评审者的视角阅读这篇论文。

请依次分析：
1. 研究问题是什么？为什么值得研究？
2. 作者提出了什么假设，使用了什么研究设计和方法？
3. 数据、样本、实验条件、对照设置及统计方法是否支持结论？
4. 论文声称的创新点是什么？哪些真正得到研究证据支持？
5. 作者是否混淆相关性与因果性，或将局部结果推及更广泛场景？
6. 研究有哪些局限、混杂因素、替代解释或复现障碍？
7. 这项研究对现有知识和实际应用增加了什么？
8. 如果进一步验证，最值得补充什么实验或证据？

请先用通俗语言解释研究，再进行专业评价。对关键数据、实验结果和作者结论注明章节、图表或页码。

区分“作者声称”“实验观察”“根据证据可以推断”与“尚未证明”。论文没有提供的信息，明确指出缺失。
{{< /prompt >}}

## 05. 行业研究：重点检查预测依据

行业报告、战略规划和咨询材料经常包含市场预测、竞争判断和行动建议。这类结论对假设条件很敏感，尤其需要检查数据口径和预测方法。

{{< prompt id="industry" title="行业研究：趋势判断与预测假设" category="研究" use="行业报告、咨询报告、市场研究、战略规划" >}}
请分析这份行业研究或战略报告，重点检验其结论能否用于实际决策。

请说明：
1. 报告对市场规模、竞争格局和行业趋势作出了哪些主要判断？
2. 这些判断使用了什么数据？数据来源、统计范围、时间和口径是否明确？
3. 增长预测基于哪些驱动因素和假设？是否给出预测方法？
4. 哪些变量变化最可能使结论失效？
5. 报告是否存在选择性使用案例、外推过度或商业立场影响？
6. 建议方案需要哪些资源、能力和外部条件？
7. 哪些结论比较可靠，哪些仅适合当作有待验证的假设？

如有充分数据，请给出乐观、基准、悲观三种情景，说明各情景的假设和触发条件。

如果缺乏量化依据，请只作定性情景分析，不要编造市场规模、增长率或概率。

最后提出对经营决策最有价值的三个判断，以及每个判断应继续核验的数据。
{{< /prompt >}}

## 06. 反向核验：让模型重新检查自己

这组适合接在前面任意一次分析之后。即使第一次回答条理清晰，也值得复查其中的证据和推理，尤其是涉及人事、投资和重要经营决策时。

{{< prompt id="countercheck" title="反向核验：检查刚才的分析" category="校验" use="重大决策、复杂材料、存在较多推断的分析" >}}
请重新审视你刚才的分析，站在持不同意见的专业评审者角度进行反向核验。

1. 找出最可能存在错误或过度推断的三个判断。
2. 分别核查原文证据、推理过程和隐含假设。
3. 尝试提出能解释同一事实的其他可能性。
4. 说明每项判断应当保留、修正，还是暂时搁置。
5. 对无法从原文确认的内容，明确写出需要补充什么材料。
6. 给出修订后的主要结论，并说明判断可靠性及原因。

请不要为了反驳而反驳。如果原判断证据充分，应明确保留。
不要虚构新的来源、数据或反例。
{{< /prompt >}}

## 一个例子：岗位调整是否意味着降薪

假设一份岗位价值评估汇报列出了提级、降级岗位，也提出“岗级决定薪级上限，各单位确定具体薪级薪档”。

只提取摘要，得到的信息是岗位价值评价体系发生了调整。进一步阅读则应发现三个层次：

- **原文事实：** 岗位等级发生调整，岗位等级和个人薪级分别管理。
- **可以推断：** 岗位等级变化可能影响个人未来的薪酬空间，具体影响取决于后续薪酬适配办法。
- **原文未交代：** 现有人员是否同步调整工资、是否保留原待遇、何时执行、涉及多少人、工资总额是否变化。

因此，一份有用的阅读结果应当提出这样的问题：

> 对已经在岗的员工，提级、降级究竟怎样影响现有薪酬与未来薪酬上限？新旧制度有什么过渡安排？

这个问题比重复报告中的“优化岗位价值分布”更有助于理解改革的实际后果。

## 使用时需要注意

**能找到出处的结论，才方便核对。** 对 PDF、Word 或报告截图，要求模型标明页码、章节和表格。涉及关键数字时，最好回看原文，尤其是表格、脚注和附件。

**缺少的信息应当保留为空缺。** 作者没有披露预算、样本量或实施细则，就应明确写出缺口。模型可以解释缺失信息为何重要，但不能用合理想象填补事实。

**把推断当作可检验的假设。** 推断有价值，但应说明依赖哪些条件。还应当考虑反例和其他解释。

**涉密或内部材料应谨慎上传。** 使用公开云端模型前，确认数据分类、单位制度和所用服务的数据处理要求。必要时先脱敏，或使用获准的内部环境。

我更愿意把大模型当作一名会追问的阅读助手。它能缩短整理材料的时间，也能帮助发现遗漏。但最终判断仍需要回到事实、证据和具体情境。
