在 ChatGPT 中上传一张照片，可以用自然语言描述希望实现的后期效果。为了方便以后检索、复用，我把一组与摄影后期有关的提示词整理成了中文版本。

这 10 条提示词按五类场景归档，覆盖人像增强、电影氛围、照片修复、商品拍摄和旅行风光。单条提示词适合快速尝试；对真实性有要求的照片，建议追加文末的通用约束。

> **来源与整理说明：** 整理自 X 用户 [@Bitturing 于 2026 年 11 月 5 日发布的提示词线程](https://x.com/Bitturing/status/2118171195631923348)。以下根据原意进行中文规范化和少量措辞优化。提示词的效果取决于原图、模型及编辑范围，不能保证像素级保真。

## 一、人像与人物摄影

{{< prompt id="portrait" title="01 · 专业人像增强" category="人像" use="日常人像、家庭合影、自然肖像" >}}
请以专业人像摄影师的标准编辑我上传的照片。优化面部受光与整体曝光，平衡肤色，自然减轻临时性皮肤瑕疵，适度增强眼睛的清晰度，并为背景增加柔和且合理的虚化。保留人物原有的五官、表情、面部轮廓和真实皮肤纹理，避免磨皮过度。
{{< /prompt >}}

{{< prompt id="business" title="02 · 专业商务头像" category="人像" use="职业头像、个人简介、工作场景" >}}
请将这张日常人像处理成自然、专业的商务肖像。使用柔和均匀的棚拍式光线和简洁中性的背景，适度修饰皮肤与衣物细节，整体呈现克制、可信赖的职业形象。保留人物真实的面部特征、发型和自然表情；未经要求不要更换服装或改变人物身份特征。
{{< /prompt >}}

{{< prompt id="fashion" title="03 · 高级时尚大片" category="人像" use="人像写真、时尚风格摄影" >}}
请将照片调整为高级时尚杂志的摄影质感。使用有层次的棚拍光线、克制而精致的对比度、协调的色彩分级和细腻的人像修饰。保留原始服装、面部特征、身体比例与人物姿态，让结果具备时尚摄影的精致感，同时避免不真实的皮肤与形体变化。
{{< /prompt >}}

## 二、电影与摄影风格

{{< prompt id="cinema" title="04 · 电影级视觉效果" category="光影风格" use="人物街拍、夜景、氛围摄影" >}}
请把这张照片处理成电影剧照的视觉质感。结合原场景建立有戏剧性的明暗关系，提升暗部层次，进行统一而克制的专业调色，并加入轻微的胶片颗粒。让画面更有叙事氛围，保持主体外观与环境关系可信，避免过度压暗或夸张的色偏。
{{< /prompt >}}

{{< prompt id="dslr" title="05 · 单反与 85mm 人像镜头质感" category="光影风格" use="人物半身像、特写、主体突出" >}}
请参照高端相机搭配 85mm 人像镜头的摄影效果优化这张照片。改善曝光与主体细节清晰度，使背景呈现符合景深逻辑的自然散景。保留主体轮廓与发丝边缘，确保虚化的强度和过渡符合原始拍摄距离，不改变人物或物体的实际特征。
{{< /prompt >}}

{{< prompt id="golden-hour" title="06 · 黄金时段暖光" category="光影风格" use="室外人像、日落、自然环境" >}}
请让这张照片呈现黄金时段摄影的光线氛围。加入方向合理的柔和暖光、温润的高光和自然阴影，适度增强金色调与画面层次。维持肤色、天空与环境颜色的真实感，保留原始场景和细节，避免出现多个矛盾光源。
{{< /prompt >}}

## 三、照片修复与清理

{{< prompt id="cleanup" title="07 · 清除不需要的物体" category="修复清理" use="游客清理、背景杂物、构图净化" >}}
请移除照片背景中分散注意力的杂物、无关人物或指定的干扰物。依据相邻区域的纹理、透视结构、光线方向与阴影自然补全缺失位置。保持主要人物、建筑、景观以及未指定区域不变，避免出现重复纹理和不合理的边缘。
{{< /prompt >}}

{{< prompt id="restoration" title="08 · 旧照与模糊照片修复" category="修复清理" use="老照片、褪色照片、轻度模糊照片" >}}
请以专业数字修复的标准处理这张旧照片。降低噪点，修复可辨认的划痕和污渍，校正明显色偏与褪色问题，适度改善清晰度和层次。优先依据现有画面恢复细节，保留真实的五官与历史信息；无法确认的区域不要自行编造，并避免将人物修成现代美颜风格。
{{< /prompt >}}

## 四、商业产品摄影

{{< prompt id="product" title="09 · 专业产品广告摄影" category="产品摄影" use="电商展示、产品宣传、商品主图" >}}
请将这张产品照片优化为专业商业摄影效果。改善整体布光，控制不必要的强烈反光，形成方向合理的接触阴影，并设置干净、精致且与产品定位一致的背景。准确保留产品的外形、比例、颜色、材质、品牌标识及可读标签，避免擅自改变型号与产品结构。
{{< /prompt >}}

## 五、旅行与风光摄影

{{< prompt id="travel" title="10 · 旅行与风景摄影增强" category="风光摄影" use="山川湖泊、城市旅行、日出晨雾" >}}
请按照专业旅行及自然风光摄影的标准优化这张照片。平衡天空与前景的曝光，提高可辨认的景观细节和局部层次，调整自然色彩，并适度增强画面的空气透视和空间深度。保留真实的地形、建筑、植被和天气特征，不凭空增加景物或制造不符合原场景的光照。
{{< /prompt >}}

## 六、通用的原图保真约束

如果希望在改善质感的同时尽量保留原照片，可以将下面这段文字**接在任意一条提示词之后**。对老照片修复、历史档案与纪实照片，应当格外审慎。

{{< prompt id="guardrails" title="附加 · 通用图片编辑约束" category="通用模板" use="上述任一提示词均可配合使用" >}}
请以我上传的原始照片为基础完成编辑。

1. 保持主体身份、面部特征、身体比例与原始构图的一致性。
2. 保留真实的材质、纹理、环境细节与空间透视关系。
3. 优先优化曝光、白平衡、局部光影、色彩和细节层次。
4. 避免过度锐化、塑料质感、夸张 HDR、异常饱和度和不自然的背景虚化。
5. 除我明确要求修改的区域外，尽量保留原画面内容。
6. 保持原照片宽高比，并尽可能输出高质量、高清晰度图像。

整体追求自然、真实、专业的摄影后期效果。
{{< /prompt >}}

## 七、使用时需要注意什么

建议一次先使用一条主提示词，观察结果后再微调。需要同时实现两类效果时，可以明确主次，例如以人像自然增强为主、暖光氛围为辅。

AI 图片编辑可能重新生成局部区域。即使提示词强调保留原始细节，最终结果仍可能与原图出现差异。用于新闻报道、身份核验、证据留存、历史档案或商品真实性证明时，应保留原始文件，并对编辑范围作出必要说明。
